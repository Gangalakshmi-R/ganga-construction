# 🏗️ Ganga Construction Website

A modern, responsive full-stack construction company website developed for **Ganga Construction**, providing an elegant online presence for showcasing construction services, completed projects, client testimonials, cost estimation, and enquiry management.

---

## 🌐 Live Demo

**Frontend:** https://ganga-construction.onrender.com

---

## ✨ Features

* Responsive modern UI with Material UI
* Premium Hero Section
* About Ganga Construction
* Services Showcase
* Completed Projects Gallery
* Client Testimonials
* Construction Cost Estimation
* Contact & Consultation Form
* WhatsApp Integration
* Google Maps Location
* Smooth Animations (AOS)
* Image Uploads using AWS S3
* RESTful Spring Boot Backend
* MySQL Database Integration
* Responsive Navigation
* Professional Footer

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Material UI
* React Router
* Axios
* AOS (Animate On Scroll)
* Swiper.js

### Backend

* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* Maven

### Cloud & Deployment

* Render (Frontend & Backend)
* Railway MySQL Database
* AWS S3 Storage
